DESKTOP COMPANION

Better A2

A Windows desktop application with character information, combat records, map tools, gathering and route controls, MOBFARM, and a configurable overlay.

01 / OVERVIEW

Character & records

Review character details, combat history, training-dummy runs, loot sessions, and activity data saved by the app.

02 / MAP & ROUTES

World tools

View the map, configure gathering areas, manage route packages, and review nearby tracked entities.

03 / OVERLAY

At-a-glance panels

Use movable overlay panels for DPS and pet tracking, with configurable visibility and placement.
